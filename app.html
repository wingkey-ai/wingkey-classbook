윙키클래스북 앱 설치

앱스토어 없이 휴대폰 홈 화면과 컴퓨터 바탕화면에 윙키클래스북 아이콘을 만들 수 있어요. 설치는 무료이고, 아이콘을 누르면 주소창 없이 앱처럼 바로 열립니다.

교재 샘플 보기

이미 앱으로 설치되어 있어요.

지금은 카카오톡·네이버 같은 앱 안의 브라우저로 보고 있어요. 설치하려면 먼저 크롬(안드로이드)이나 사파리(아이폰)로 열어 주세요.
크롬으로 열기

기기별 설치 방법

안드로이드 휴대폰지금 기기

  1. 크롬에서 이 페이지를 엽니다.
  2. 위의 "지금 앱 설치" 버튼을 누르거나, 오른쪽 위 ⋮ 메뉴 → "앱 설치"(또는 "홈 화면에 추가")를 누릅니다.
  3. 홈 화면에 윙키클래스북 아이콘이 생깁니다.

아이폰·아이패드지금 기기

  1. 사파리에서 이 페이지를 엽니다. (카카오톡·네이버 앱 안에서는 오른쪽 아래 메뉴 → "Safari로 열기")
  2. 아래쪽 공유 버튼(네모에 위 화살표)을 누릅니다.
  3. "홈 화면에 추가"를 고르고 오른쪽 위 "추가"를 누릅니다.

윈도우 PC지금 기기

  1. 크롬 또는 엣지에서 이 페이지를 엽니다.
  2. 위의 "지금 앱 설치" 버튼을 누르거나, 주소창 오른쪽의 설치 아이콘(모니터에 아래 화살표)을 누릅니다.
  3. 시작 메뉴와 작업 표시줄에 고정할 수 있습니다.

맥지금 기기

  1. 크롬 또는 엣지: 위의 "지금 앱 설치" 버튼이나 주소창 오른쪽 설치 아이콘을 누릅니다.
  2. 사파리(macOS 14 소노마 이상): 메뉴 막대 "파일" → "Dock에 추가"를 누릅니다.
  3. Launchpad와 Dock에서 앱처럼 열 수 있습니다.

바탕화면 바로가기 파일

설치 기능이 없는 브라우저라면 바로가기 파일을 내려받아 바탕화면에 두세요. 더블클릭하면 윙키클래스북이 열립니다.

자주 묻는 질문

앱스토어나 플레이스토어에서 받는 앱인가요?

아니요. 웹사이트를 그대로 앱처럼 설치하는 방식(PWA)이라 스토어 없이 무료로 바로 설치되고, 내용이 바뀌면 자동으로 최신 상태가 됩니다.

설치하면 무엇이 달라지나요?

홈 화면·바탕화면 아이콘으로 바로 열리고 주소창 없이 전체 화면으로 보입니다. 한 번 본 교재 샘플 그림은 저장되어 인터넷이 약한 곳에서도 다시 볼 수 있습니다. 원어민 듣기와 교재 신청은 인터넷이 연결돼 있어야 합니다.

지우려면 어떻게 하나요?

휴대폰은 아이콘을 길게 눌러 삭제하고, 컴퓨터는 앱을 연 뒤 오른쪽 위 메뉴에서 "제거"를 누릅니다.
